| A10 | P1a-02 | Rate limits per address and per IP (architecture §8) | Per user: at most `links_per_window` (5) links per link lifetime; further requests send nothing and are audited `auth.link_refused`. Per IP: not in the API; left to the proxy (backlog). |

| A12 | P1a-03 | "Operator role lives outside tenant RLS and is checked by a separate dependency" | An operator is an active user of the internal (platform) tenant listed in `operators`, signed in through Authentik; the Phase 0 bearer token never reaches the console. `app.operator.deps.require_operator` checks this without any tenant role, and operator routes then run as the NOLOGIN role `askspore_operator` (`SET LOCAL ROLE`; the app role may assume it but does not inherit it), whose policies see every tenant but whose privileges cover only tenants, users (create), entitlements, notices and audit events: it cannot read conversations, messages, citations, feedback, sign-in links or sources (revision 0006, tested).
